# PROGRESS — TuneUp

> File ini dipakai bersama oleh **Codex (ChatGPT)** dan **Antigravity**.
> Baca dulu sebelum mulai kerja, dan perbarui setelah selesai (tambahkan entri log di bawah).

## Ringkasan
- Game musik **TuneUp**, tayang di https://tuneup.pages.dev/ (Cloudflare Pages project: `tuneup`; project lama `namethetrack` sudah dihapus).
- Audio: preview iTunes (sering mulai dari tengah lagu; Deezer sudah dites, sama saja).
- Katalog: `songs.js` (~30.8k lagu Western). Tool: `node tools/expand-catalog.cjs`.
- Aturan katalog: lagu **Western** untuk mode utama, **tanpa versi live**, **duplikat disaring**.
- Untuk perubahan desain, user lebih suka diberi **preview dulu** sebelum diunggah ke web utama.

## Sudah selesai
- Warna tingkat kesulitan Easy–Impossible tetap terlihat saat tidak aktif.
- Sound effect dihapus (permintaan user); confetti tetap ada.
- SEO: judul, heading, dan schema "Name The Track"; sudah terindeks Google. Nama situs di Google masih "Cloudflare" (tunggu Google).
- Optimasi animasi. Lag di laptop ternyata karena *Animation effects* Windows mati (sudah beres).
- Tombol **Copy result** gabungan (gambar PNG + teks hasil + link via `ClipboardItem`, dengan fallback teks + link) dan **Report this song**.
- Tap highlight biru dimatikan di semua tombol.

## Wave 45 — Fix Play Button vs Skip Audio & Win Chime Playback Reliability (2026-11-20)
- **Root Causes Fixed (`app.js`)**:
  1. `playClip()` previously awaited an async `seek(dari)` event BEFORE calling `audio.play()`, which could break browser user-activation (`NotAllowedError` / silent reveal autoplay) when resetting `currentTime` to `0` after pressing Play. Now sets `audio.volume` and `audio.currentTime = dari` synchronously right before `beginPlayback()`, and guards `if (audio.seeking)` inside `tick()` so replaying a `0.1s` clip can never stop prematurely on frame 1.
  2. The `0.1s` clip fade-out window (`left < 0.1`) previously attenuated 100% of the `0.1s` clip from millisecond 0; capped fade to `Math.min(0.08, batas * 0.25)` so `0.1s` plays cleanly at full volume.
  3. Added `unlockSfx()` on `playClip()`, scheduled `playSfx()` notes after `ctx.resume()` when `suspended`, and raised win chime gain (`0.16 * S.vol`, max `0.20`) so victory chimes remain crisp alongside revealed song playback.
