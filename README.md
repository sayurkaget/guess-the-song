# Guess The Song

A daily song-guessing game in the spirit of Heardle. Hear a split second of a track and
name it. One run is five stages that keep getting harder — Easy through Impossible — with
the opening clip shrinking from 2 seconds down to 0.1.

**Play:** https://sayurkaget.github.io/guess-the-song/

- 992 songs, filterable by region, genre and era
- Audio comes from the public iTunes Search API (30-second preview clips)
- Everything runs in the browser; progress is stored locally, no accounts
- Installable to your phone's home screen

Missing a stage does not end the run — you carry on to Impossible either way, and your
score is how many of the five you nailed.
